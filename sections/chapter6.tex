\chapter{Cognitive Radio Networks}
\label{sec:chapter6}

This chapter explores Cognitive Radio (CR) systems, focusing on opportunistic spectrum access, dynamic channel sensing, and primary-secondary user coexistence.

\section{Overview of Contributions}
Contributions from researchers under the Mobile Computing Lab include:
\begin{itemize}
    \item \textbf{Basker Deppuri:} Spectrum sensing algorithms and optimization under uncertainty.
    \item \textbf{Senthil Murugan:} Decision-theoretic models (e.g., MDPs) for channel selection.
    \item \textbf{Vivin Thomas:} Security and routing in multi-hop cognitive networks.
\end{itemize}

\section{Dynamic Spectrum Access and Sensing Mechanisms}
We analyze how secondary users opportunistically exploit spectrum white spaces without causing harmful interference to primary users, detailing cooperative sensing protocols and spectrum sharing.

\chapter{Advanced Features and QoS in IEEE 802.11}
\label{sec:chapter2}

This chapter explores the evolution of QoS, frame optimization, and physical-MAC layer enhancements in the modern iterations of the IEEE 802.11 standard (ranging from 802.11e to 802.11be/Wi-Fi 7).

\section{EDCF, Inter-Frame Spaces, and Access Categories}
\begin{itemize}
    \item \textbf{Enhanced Distributed Channel Access (EDCA/EDCF):} Introduced in 802.11e to provide quality of service. It defines four Access Categories (AC): Background (AC\_BK), Best Effort (AC\_BE), Video (AC\_VI), and Voice (AC\_VO).
    \item \textbf{Short Inter-Frame Space (SIFS):} The shortest spacing between frames, used for high-priority transmissions like ACKs and CTS.
    \item \textbf{Service Differentiation & QoS:} Different ACs have different Arbitrary Inter-Frame Spaces (AIFS) and Contention Window (CW) limits, giving higher priority traffic faster access to the medium.
\end{itemize}

\section{MAC-Level Frame Aggregation and Block ACK}
To reduce protocol overhead, modern standards combine multiple frames before transmission:
\begin{itemize}
    \item \textbf{A-MSDU (Aggregate MAC Service Data Unit):} Groups multiple MSDUs into a single MPDU.
    \item \textbf{A-MPDU (Aggregate MAC Protocol Data Unit):} Groups multiple MPDUs into a single Physical Layer Convergence Procedure (PLCP) Service Data Unit (PSDU).
    \item \textbf{Block Acknowledgment (Block ACK):} Allows a receiver to acknowledge multiple MPDUs in an A-MPDU using a single control frame, saving significant overhead.
\end{itemize}

\section{Transmission Opportunity (TXOP)}
A TXOP is a bounded time interval during which a station can transmit as many frames as possible (using frame burst and SIFS) after winning contention, preventing channel re-contention for every single frame.

\section{Power Saving: Target Wake Time (TWT)}
Introduced in 802.11ax (Wi-Fi 6), TWT allows APs and client stations to negotiate specific times to wake up and exchange data. This drastically improves battery life and reduces contention in high-density environments.

\section{High Throughput PHY-MAC Integrations}
\begin{itemize}
    \item \textbf{MU-MIMO (Multi-User Multiple Input Multiple Output):} Allows the AP to transmit to or receive from multiple users simultaneously over different spatial streams.
    \item \textbf{OFDMA (Orthogonal Frequency Division Multiple Access):} Divides the channel bandwidth into smaller sub-channels (Resource Units), enabling simultaneous transmission from different stations.
    \item \textbf{BSS Coloring (BSR Coloring):} Identifies overlapping Basic Service Sets (OBSS) using colors in the PHY header, allowing stations to ignore traffic from neighboring networks and reduce collision deferrals.
\end{itemize}

\section{Next-Generation Enhancements: MLO \& Multi-AP}
With the release of IEEE 802.11be (Wi-Fi 7), the wireless standard introduces architectural updates designed to achieve extremely high throughput (EHT) and ultra-low, deterministic latency. Among the most significant MAC and physical layer enhancements are Multi-Link Operation (MLO) and Coordinated Multi-AP transmission.

\subsection{Multi-Link Operation (MLO)}
Traditional Wi-Fi devices, even if dual-band or tri-band, can only establish a single active link with an Access Point (AP) at any given time, requiring a dynamic connection switch when switching bands. MLO solves this limitation by introducing the concept of a \textbf{Multi-Link Device (MLD)}. An MLD contains multiple physical PHY entities but exposes a single MAC interface to the upper network layers (represented by a logical Link Establishment and Management entity). 

This architecture allows a client MLD to establish concurrent active links with an AP MLD across different frequency bands (e.g., 2.4~GHz, 5~GHz, and 6~GHz) or different channels within the same band. Link communication modes in MLO include:
\begin{itemize}
    \item \textbf{Simultaneous Transmission and Reception (STR):} The device can transmit on one link while receiving on another link simultaneously. This requires significant physical isolation between the transceivers to prevent self-interference.
    \item \textbf{Non-Simultaneous Transmission and Reception (Non-STR / NSTR):} When transceivers are placed too close together, a transmission on one band (e.g., 5~GHz) leaks and blinds the receiver on a neighboring band (e.g., 6~GHz). In NSTR mode, channel access must be coordinated across links to prevent overlapping TX-RX states.
\end{itemize}

By dynamically aggregating links or routing packets along the link with the lowest current contention, MLO significantly increases peak throughput, improves link reliability, and reduces worst-case latency by avoiding congested channels.

\subsection{Coordinated Multi-AP Operation}
In dense enterprise environments, performance is heavily bottlenecked by Overlapping Basic Service Sets (OBSS), leading to high co-channel interference and inefficient contention. To address this, IEEE 802.11be defines explicit coordination protocols across neighboring Access Points (APs) sharing the same backbone network:
\begin{itemize}
    \item \textbf{Coordinated Spatial Reuse (C-SR):} APs exchange information regarding transmit powers and path losses. During an active transmission from a primary AP to its client, a coordinated secondary AP can transmit concurrently at a controlled, reduced power level, ensuring that it does not disrupt the primary AP's reception.
    \item \textbf{Coordinated Beamforming (C-BF):} Multiple APs perform joint null-steering. A neighboring AP structures its beamforming vectors to place spatial nulls at the location of active clients of the main AP, preventing interference.
    \item \textbf{Coordinated Orthogonal Frequency Division Multiple Access (C-OFDMA):} The available channel bandwidth is dynamically divided into Resource Units (RUs) and shared among neighboring APs. This allows concurrent orthogonal transmissions without spatial collisions.
    \item \textbf{Joint Transmission (JT):} Multiple APs jointly transmit the same data payload to a single client device. This converts destructive interference into constructive multipath combining, maximizing signal-to-interference-plus-noise ratio (SINR).
\end{itemize}
